Référencement léger des Flibustiers, en remplacement de Yoast : balises, indexation, plan du site, données structurées, fil d'Ariane, redirections et visibilité dans les IA.

== Description ==

* Titre et description pour Google sur chaque contenu et chaque terme, avec aperçu du résultat ; modèles par défaut à variables.
* Indexation : noindex par contenu, type ou taxonomie ; archives d'auteur et de date redirigées ; pages de médias redirigées vers le fichier.
* Plan du site natif de WordPress (wp-sitemap.xml) épuré (contenus masqués exclus) et daté ; anciennes adresses Yoast redirigées.
* URL canonique, Open Graph et carte X pour le partage.
* Données structurées schema.org : site, entreprise locale (reprend les Réglages du site de flib-base), page, article, fil d'Ariane, FAQ (blocs Détails).
* Fil d'Ariane : bloc pour les thèmes à blocs et shortcode [flib_fil_ariane].
* Redirections 301 / 302 / 410, import en masse, journal des pages introuvables.
* IA (GEO) : robots des IA dans le robots.txt, fichier /llms.txt.
* Import des données Yoast.
